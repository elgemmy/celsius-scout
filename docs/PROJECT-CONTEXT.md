# Project context

## Authoritative direction

Celsius Scout is a playful urban heat intelligence experience inspired by collectible player cards. City blocks, neighborhoods, or sampled locations are analyzed, scored within a comparison cohort, categorized, and represented as thermal cards with archetypes such as The Furnace, The Oasis, The Night Owl, The Marathoner, The Comeback Kid, and The Chaos Merchant.

The core combines deterministic data analysis, interactive visualization, and an agent that visibly performs useful analytical work. The agent calls structured tools to scan an area, find anomalies, compare locations, select candidates, build lineups, and inspect evidence. It may reason about and explain tool results, but it does not invent or privately calculate displayed metrics.

Candidate card dimensions include Peak, Stamina, Recovery, Comfort, Chaos, Surprise, and Peak Time. The exact formulas must be documented and tested. Scores are relative to the selected cohort rather than universal claims.

## Derived experiences

**The Average Is Lying** compares a broad representative value with the full hyperlocal distribution to reveal outliers, hidden persistence, different peak times, and misleadingly similar averages.

**Festival Tetris** evaluates a fictional outdoor schedule against the same thermal dataset, then lets an agent select and explain a constrained before-versus-after plan. Exposure calculation and constraint validation remain deterministic.
