# Three-minute demo script

## 0:00–0:25 — identity

“A city average gives you one number. Celsius Scout asks a better question:
what kind of thermal player is each location?”

Point out the active cohort, time window, threshold, and synthetic-preview label.

## 0:25–1:00 — thermal fraud

Run **Thermal fraud**. Show the selected tile, its player card, time-weighted
mean, observed peak, peak-to-mean gap, and the real executed tool name.

Say: “The playful label is memorable; the calculation is traceable. Fraud here
means the mean masks the peak—not that the data is deceptive.”

## 1:00–1:35 — different twins

Run **Different twins**. Show both selected locations and the behavior-distance
evidence. Select each tile so the card curve changes.

Say: “Similar averages do not imply similar exposure patterns. Persistence,
recovery, variability, and peak timing change the story.”

## 1:35–2:10 — agent

Ask: **“Find an underrated cool location.”**

Point to the mode label and executed tool. If model credentials are absent, say:
“The deterministic fallback runs the same evidence tool, so the demo never
depends on a model or network call.”

If the LLM is configured, say: “The model chooses and explains tools. The server
rejects unsupported numbers; code owns the calculations.”

## 2:10–2:40 — the average is lying

Scroll to the derived panel. Contrast the broad cohort mean, local range, and
share of observed tile-hours above the threshold.

Say: “This is not a separate analytics product. It is a summary from the same
engine that produced the cards and agent evidence.”

## 2:40–3:00 — close

“Celsius Scout turns FortyGuard-compatible hyperlocal temperature profiles into
something discoverable, explainable, and actionable: scout a pattern, inspect
the proof, then use the result to make a selection.”

Only mention Festival Tetris if its branch remains fully green: “The same engine
also powers a constrained event-schedule proof, without changing the flagship.”
