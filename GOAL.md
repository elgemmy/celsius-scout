# Team goal

Deliver a polished, reliable Celsius Scout core that converts a thermal time-series cohort into traceable player-card metrics, cohort-relative scores, deterministic archetypes, useful scouting comparisons, and evidence-grounded explanations.

## The coherent loop

1. Load a deterministic demo cohort or normalized FortyGuard data.
2. Calculate raw thermal features with pure, tested functions.
3. Normalize scores only against the active comparison cohort.
4. Assign an archetype using explicit deterministic rules.
5. Render the location on a map, as a card, and in a comparison.
6. Let the scout agent select tools and explain their structured results.

## Done means

- A new user understands the player-scouting metaphor within 15 seconds.
- Every displayed number can be traced to an input series and documented formula.
- Re-running analysis on the same cohort returns the same result.
- At least six distinct thermal profiles produce sensible, tested archetypes.
- The scout can answer four high-value prompts end to end without invented values.
- The UI remains usable with no FortyGuard or LLM key.
- Live API and LLM failures degrade visibly and safely to the reliable core.
- Tests cover formulas, normalization, archetype boundaries, and scouting selections.
- The production build and the critical browser flow pass.
- The repository explains setup, architecture, data honesty, and the demo story.

## Cut line

The Average Is Lying and Festival Tetris receive only thin, convincing slices until the core above passes. Satellite/street-view enrichment, accounts, persistence, elaborate maps, unconstrained chat, health-risk claims, causal explanations, and intervention-effect predictions are deferred.
